# Lublin today

## About

Web application that aggregates public transport schedules (using ZTM Lublin open data, and GTFS if available) and city events.

## Features

Stop search and upcoming departures, an event feed with filters (date, category), favorite stops, responsive mobile-friendly design, error handling, and a “data unavailable” state.

## Technology

- JavaScript
- React
- Node.js
- Express
- MongoDB
